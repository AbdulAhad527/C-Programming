Explanation of My Al-Quran Information System Project

This is a C program called Al-Quran Information System. Its main purpose is to show information about all 114 Surahs of the Quran and allow the user to listen to their audio recitation.

How the Program Works:

Data Structure:
The program uses a struct called Surah. This stores information about each Surah, like:

Number of the Surah

Name of the Surah

Waja-e-Tasmiya (reason for naming)

Background of the Surah

Topics discussed in the Surah

Number of Ayat and Ruku

Path of the audio file

Audio Playback:
The program has a function called playAudio() that uses Windows Multimedia API (mciSendString) to play mp3 files.

User Interface:

The program shows a list of Surahs with their numbers and names.

The user enters a Surah number.

The program displays detailed information about that Surah.

The user can choose to listen to the Surah or skip to select another.

Looping:
After listening or skipping, the program goes back to the list to allow the user to select another Surah.

Important Note about Compilation:

This program uses mmsystem.h and the audio playback function.

If you do not add winmm.lib in the Linker settings, the program will not run.

This is because mciSendString() function is defined in winmm.lib, and without linking it, the compiler cannot find this function.

Summary:

This program is a simple educational project that combines:

Arrays and structs to store data

Functions to play audio

User input and output to display information

It can be used to learn about programming, Windows audio functions, and the Quran at the same time.
